# Iconography and imagery

- Small, consistent vector icons (usually 16–18px in toolbar/sidebar) with consistent stroke ~1.7px. Primary navigation includes text, not icons only unless collapsed with labels/tooltips.
- Use one icon system per project. Prefer existing installed icon library; do not introduce two libraries or counterfeit SF Symbols distributions.
- Icon-only interactive button requires `aria-label`, adequate hit area, focus treatment, loading/disabled states.
- Prefer functional visualizations; charts only when they answer decisions. Avoid decorative stock photos and gradients in dense work surfaces.
- Visual status pairing: color + icon/shape + readable label. A red dot alone is not an error explanation.
- For an application icon or original brand illustration, obtain project-specific assets from the owner; don't copy Apple's official marks.
